PPHA – Pre-Post Heart Attack Alert Wristband

 Overview

PPHA (Pre-Post Heart Attack Alert)** is an intelligent wearable wristband designed for elderly and high-risk individuals. The system continuously monitors **heart rate (BPM)** and detects both gradual risk patterns and sudden cardiac abnormalities. When dangerous trends or extreme changes are identified, alerts are sent to caregivers for immediate attention.

---
 🚨 Problem

Heart attacks often occur without clear early warnings. Elderly people living alone are especially vulnerable because abnormal heart conditions may go unnoticed until it is too late.

---

 💡 Solution

PPHA combines continuous heart monitoring with pattern analysis to detect:

 1️⃣ Pre-Heart Attack Risk**

The band analyzes a *series of irregular BPM readings* that may indicate stress buildup, heart strain, or arrhythmia risk. Caregivers receive alerts before the condition becomes critical.

2️⃣ Post-Event Emergency Detection**

If BPM suddenly spikes (tachycardia) or drops sharply (bradycardia), the system flags it as an emergency and sends an immediate alert.

---
 ⚙️ Features

* Continuous BPM monitoring
* Abnormal pattern detection
* Emergency alerts for sudden heart changes
* Medicine reminder system
* Caregiver notification support
* Frontend dashboard for live health data

---
 🛠 Tech Stack

* Sensor: **MAX30102**
* Microcontroller: ESP32
* Frontend: HTML, CSS, JavaScript
* IoT Communication

---

🎯 Goal

To reduce response time during cardiac events and provide early warnings that can potentially save lives.
